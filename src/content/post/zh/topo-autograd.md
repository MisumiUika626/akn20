看了Kapathy的zeroToHero系列视频，我发现之前神经网络中的参数通常只是普通数字（weight = 0.5） 但是普通数字只保存了当前值，并不知道： 
- 这个值由哪些计算产生 
- 它参与了哪些运算 
- loss 对它的影响如何传播 
- 因此需要将普通数字升级为一个具有计算历史的对象 Value。
所以看到了他写的自动微分引擎就决定把它自己写一遍装到我的小垃圾上，

将**计算图中的节点信息**（数值、梯度、依赖节点等）保存在类 `Value` 中，然后通过拓扑排序建立计算图来实现反向传播，之后梯度的累计，参数的修改就可以直接对这个类`Value`执行。

## 运算过程模拟
```
a = Value(2)
b = Value(3)
c = a * b

loss = c

此时计算图:
a ----\
       * ---- loss
b ----/
Value 不仅保存 c=6，
还保存 c 是由 a 和 b 计算得到的关系。
```
## 关于拓扑排序(Topological sort)

- 在一个有向无环图（DAG）中，找到一个**满足所有依赖关系**的线性执行顺序。
	- 比如我们有A->B表示B依赖A，那拓扑排序必须保证A排在B前面
	- 我想的是：
		 拓扑排序是在保留有向图依赖关系的前提下，
		 **将原本具有分支结构的二维**（或更高维直观结构）**压缩为一维线性序列**。
		 它丢弃的是节点在图中的空间布局信息，**保留节点之间的先后约束关系**。
	
- 反向传播需要按照计算图的逆拓扑序执行。 因为一个节点的梯度需要先收集来自所有后续节点的梯度， 然后才能继续向前传播。

以下为DFS方式的拓扑排序伪代码（来自CLRS）
```
TOPOLOGICAL-SORT(G)

1. Run DFS on G
2. When a vertex finishes, insert it to the front of a list
3. Return the list
```
