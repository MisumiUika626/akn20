# akn20 V1

User-approved brief: a personal technical blog based on Astro Kami, developed in
`/home/misumi/workspace/akn20`, published to `MisumiUika626/akn20` and GitHub Pages.
All local writes, dependency stores, temporary files and build artifacts stay in this directory.

## Architecture

Keep Kami's static Astro 7 architecture, Markdown/MDX collections, typography,
light/dark themes, RSS, sitemap and generated article cards. English lives at `/`,
Chinese at `/zh/`. Pages use `/akn20/` as their deployment base. Preserve the existing
remote history: inspection found the upstream source already imported, not an empty repo.

## Visitor experience

An understated academic home introduces the notebook, areas of interest, latest
writing and featured projects. Blog links to separate category and tag archives.
Projects uses the existing Showcase data/rendering behind `/projects/` routes.
About has independent English and Chinese documents, with only verified identity
and a GitHub contact link. No invented qualifications or results.

Posts have one category (default Notes), multiple tags and an optional translationKey.
Matching keys pair translations; a missing translation returns visitors to the other
language's blog and must not advertise a nonexistent translated article.
Search uses Pagefind's generated static index and localized default UI on `/search/`.

Replace published upstream demo posts with explicitly labeled bilingual samples.
Retain demo assets for optional later use. Projects initially lists this actual blog.
Comments and analytics stay opt-in. No accounts, database or editorial backend.
